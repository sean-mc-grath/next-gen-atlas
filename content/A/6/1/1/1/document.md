###### A.6.1.1.1 - Nested Halo Agent Artifacts [Core]

Prime Agent Artifacts must include the Agent Artifacts of any [Halo Agents](e6261608-c225-452a-aca7-6eb7b5ed2d58) that the Prime envelops. [Halo Agents](e6261608-c225-452a-aca7-6eb7b5ed2d58) are [Microagents](d9e38978-fd7f-4e6d-98e6-45b2f5d6a3ce) whose Agent Artifacts are nested inside the Agent Artifacts of a Prime Agent, rather than appearing as standalone entries in the [Agent Scope](4a08ca6c-e652-49e4-9b79-4831b20e600a).

For each Halo Agent enveloped by a Prime, the Prime Agent Artifacts must at minimum include the requirements specified in [A.6.1.1.1.1 - Mandate And Configuration Requirements](ee2c4e23-78f4-4540-9e51-14c78b0379f1), [A.6.1.1.1.2 - Halo Token Issuance And Prime Limits](80dd40fc-9805-4b16-aa28-ba2115d29716), [A.6.1.1.1.3 - Risk Limits And Collateral Eligibility](387686fe-0ed5-407c-b519-19dc7507e3d4), and [A.6.1.1.1.4 - Reporting And Sentinel Integration](6cd0b997-9213-4200-ab3c-39d96c09b5ae).

Prime Agents may structure their nested Halo Agent Artifacts in additional detail, but they must ensure that all Halo-related Artifacts remain accessible through the Prime's Agent Artifact tree and are kept consistent with the Halo's own Agent Artifacts and the Sentinel and Laniakea interfaces.
