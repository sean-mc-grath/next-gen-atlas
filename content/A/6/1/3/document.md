##### A.6.1.3 - List Of Generator Agent Artifacts [Section]

The documents herein each set out the Artifacts for Generator Agents. Generator Agent Artifacts contain all rules, processes, parameters, and information relevant to the Agent. Individual Generator Agent Artifacts will be specified in a future iteration of the Atlas.
