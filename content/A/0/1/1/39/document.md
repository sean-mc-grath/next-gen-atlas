###### A.0.1.1.39 - Agent [Core]

Agents are first-class economic citizens of Sky that autonomously pursue business opportunities within mandates defined by the Atlas and the Sky Agent Framework. Each Agent has its own Agent Artifact and governance token (or equivalent economic representation), and is expected to operate as an independent but governed entity inside the Sky Ecosystem.

Agents are organized into Macroagents and Microagents, as defined in [A.0.1.1.42 - Macroagent](08a64545-48f6-4849-b876-bbdba1f74a64) and [A.0.1.1.43 - Microagent](d9e38978-fd7f-4e6d-98e6-45b2f5d6a3ce). Macroagents hold their Agent Artifacts directly in the Agent Scope and interface directly with Sky Core. Microagents have their Agent Artifacts enveloped inside the artifacts of Macroagents and extend them with specialized functionality.

Initially, the creation of an Agent results in a Proto-Agent, which lacks any specialized role. To gain functionality within the Sky Ecosystem, a Proto-Agent must deploy a Transformation Primitive to transform into a specific Agent sub-type (see [A.2.2.4.1 - Agent Creation Primitive](82b95f6d-4883-4f08-ac3a-9d8189013fbe) and [A.2.2.4 - Genesis Primitives](3d5e3668-8333-4908-adcc-5784cfe7f6b5)).

Although some Agent types (such as certain Executor Agent roles) may not yet be operational, the Atlas defines the foundational rules, processes, and governance structures necessary for their eventual activation. As the Sky Ecosystem matures, these Agents are expected to become fully operative and perform essential functions in facilitating and supervising the activities of other Agents across the Sky Ecosystem.
